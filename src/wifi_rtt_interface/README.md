# wifi_rtt_interface

ROS 2 node that publishes Wi-Fi RTT range observations to every visible access point. The
data source is a pluggable backend:

| `backend_type` | Status | Source |
|---|---|---|
| `simulation_isaac_sim` | Available | Robot pose from TF plus a precomputed NLOS map from Isaac Sim |
| `android` | Planned ([#26](https://github.com/RohanDwivedi/rwifi_slam/issues/26)) | Android Wi-Fi RTT API |

## Node: `wifi_rtt_publisher`

Publishes `wifi_rtt_msgs/APRangeObservation` on `wifi_rtt_scan` at 5 Hz, the IEEE 802.11mc
scan-rate limit.

### Parameters

| Parameter | Example | Description |
|---|---|---|
| `backend_type` | `simulation_isaac_sim` | Backend to use |
| `odom_frame` | `odom` | Frame the robot position is looked up in |
| `wifi_frame` | `chassis_wifi` | Antenna frame; also the message `frame_id` |
| `simulation_isaac_sim.nlos_map_file` | `.../warehouse_nlos_map.pkl` | Precomputed NLOS map (see below) |
| `simulation_isaac_sim.grid_cell_resolution` | `0.1` | Currently unused |

[`config/isaac_sim_warehouse_config.yaml`](config/isaac_sim_warehouse_config.yaml) holds the
warehouse settings. `wifi_bringup.launch.py` in `rwifi_slam_ros2` fills in the map path.

## Simulation backend

At start-up the backend loads the NLOS map. If the file doesn't exist yet, it waits up to
five minutes, because Isaac Sim writes the map on its first run. For each scan it then:

1. looks up `odom_frame → wifi_frame` in TF;
2. finds the nearest cell of the precomputed grid;
3. for each access point, reports
   `measured = true distance + NLOS bias + hardware bias + noise`, where the noise is
   `0.4 · t(df=3) + 0.2` m.

The true distance, the bias terms, and the line-of-sight flag are included in each
`APRange` so results can be checked against ground truth. Consumers doing SLAM must use only
`measured_distance`.

### NLOS map format

[`nlos_map_schema.py`](wifi_rtt_interface/nlos_map_schema.py) defines a pickle with one
`NLOSMap` per access point (MAC address, position, hardware bias). Each holds one
`NLOSObservation` per grid cell (cell centre, LOS flag, NLOS bias). Every access point uses
the same cells in the same order. Maps produced inside Isaac Sim load in ROS without
changes: the custom unpickler remaps Isaac's module names, and both NumPy 1.x and 2.x
module paths.

The map is generated by [`precompute_nlos.py`](../simulation/isaac_sim_dev/include/precompute_nlos.py).
For each cell and access point, it raycasts and counts the rigid bodies the ray hits. Each
obstruction adds a delay drawn from `N(2.0, 0.7)` m, plus `0.02 · distance`.

> [!WARNING]
> Pickle files can run arbitrary code when loaded. Only load NLOS maps you generated
> yourself or got from a source you trust.
